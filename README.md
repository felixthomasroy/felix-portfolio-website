## ✨ About

My personal portfolio website, built with **HTML, CSS and vanilla JavaScript**, with a small **Node.js** server powering an admin panel for editing the site's content.

## 🚀 Highlights

- 📱 Responsive layout with a mobile navigation menu
- 🎬 Smooth scroll-reveal animations
- 🧩 Content driven by a single data file, so updates are easy
- 🛠️ Admin panel for managing portfolio content
- 📄 Downloadable resume and a contact form

## ▶️ Run Locally

```bash
git clone https://github.com/felixthomasroy/felix-portfolio-website.git
cd felix-portfolio-website
```

Open `index.html` in your browser to view the site. To use the admin panel, start the Node server:

```bash
node server.js
```
